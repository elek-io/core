**`docs/api-clients.md` names the deprecation warning TypeScript 7.0 now prints.** `elek generate:types js` and `elek generate:client js` compile through the tsdown you install inside the `^0.23.0` peer range, and from tsdown 0.23.5 on that compiler says "The `tsgo` generator on TypeScript 7.0 is deprecated and will be removed in the next minor. Upgrade to TypeScript 7.1 or later."

- Both commands still do their work, and the rest of the TypeScript 7 behavior the doc describes is unchanged, re-measured on tsdown 0.23.7.
- The warning is tsdown's rather than Core's, so a newer TypeScript 7 is what answers it, and Core's `typescript` peer range already allows one.
- A project with `isolatedDeclarations` on sees no warning, because declarations are generated by Oxc there.
